# Changelog

## [1.0.3] — 2026-08-10

### Безопасность и Производительность
- **Ленивая загрузка:** Пароли больше не загружаются в оперативную память при открытии списка. Расшифровка происходит только при двойном клике.
- **Очистка буфера:** Буфер обмена автоматически очищается через 30 секунд после копирования пароля.
- **Исправление утечки:** Устранена утечка памяти `SecretValue` в рабочем потоке.

### Интерфейс (UX)
- **Чистая таблица:** Убран столбец «Пароль» из главного окна.
- **Генератор паролей:** Добавлена кнопка генерации надежного пароля в диалоге создания записи.
- **Удобное копирование:** Кнопка «Копировать» теперь выглядит как иконка внутри поля пароля.
- **Валидация:** Кнопка «Сохранить» неактивна, если не заполнены обязательные поля.
- **DPasswordEdit:** Поля ввода пароля теперь имеют встроенную кнопку показа/скрытия («глаз»).

### Техническое
- Полностью прокомментирован код для подготовки к продакшену.
- Улучшена логика встраивания переводов DTK в CMake.

## [1.0.0] — 2026-08-10

### Добавлено
- Первый стабильный релиз Lib-Secret Manager.
- Управление секретами через системный keyring (libsecret).
- Нативная интеграция с DTK6 (темы, иконки, окно «О программе»).
- Поддержка .deb пакетов и AppStream метаданных.
