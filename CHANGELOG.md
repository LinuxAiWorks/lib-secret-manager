# Changelog

Все заметные изменения в проекте будут документироваться в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/),
и этот проект придерживается [Semantic Versioning](https://semver.org/lang/ru/).

## [1.0.0] — 2026-08-10

### Добавлено
- Первый стабильный релиз **Lib-Secret Manager**.
- Управление секретами в системном хранилище ключей через **libsecret**.
- Добавление новых записей (метка, имя пользователя, сервис, пароль).
- Просмотр деталей секрета по двойному клику с кнопкой «Копировать пароль».
- Удаление записей с подтверждением.
- Контекстное меню в таблице: добавить, удалить, обновить.
- Полностью русскоязычный интерфейс.
- Поддержка системных переводов **DTK6** (AboutDialog, стандартные кнопки).
- Fallback-перевод меток AboutDialog на случай отсутствия `.qm` в системе.
- Интеграция с **Deepin Tool Kit (DTK6)**: нативное окно «О программе», тёмная/светлая тема, системные иконки.
- Встроенная иконка приложения и desktop-файл.
- Готовый **.deb** пакет для Deepin / UOS / Debian-based дистрибутивов.
- AppStream метаданные для центра приложений.

### Технические детали
- Qt6 + Dtk6Widget + Dtk6Core.
- Работа с libsecret в отдельном потоке (QThread) без блокировки GUI.
- Сборка через CMake ≥ 3.16.
